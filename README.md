**Mygle** (de "My Goal") é um aplicativo em C# que ajuda vendedores a registrar vendas e calcular comissões automaticamente. Inspirado na ideia de alcançar metas, o Mygle oferece uma solução simples e prática para acompanhar o desempenho de vendas, ideal para vendedores autônomos e pequenas equipes.

## ℹ️ Sobre o Projeto

O **Mygle** foi criado para simplificar o gerenciamento de vendas e comissões. Vendedores podem registrar cada venda, definir taxas de comissão e visualizar relatórios de desempenho.

### Tecnologias Utilizadas
- **.NET 8.0**: Framework principal.
- **C# 11.0**: Linguagem de programação.

## ✨ Funcionalidades

- 📝 **Registro de Vendas**: Adicione vendas com valor, data e descrição (ex.: produto ou cliente).
- 💰 **Cálculo de Comissões**: Configure taxas de comissão e veja os valores calculados automaticamente.
- 📊 **Relatórios**: Consulte o total de vendas e comissões acumuladas.
